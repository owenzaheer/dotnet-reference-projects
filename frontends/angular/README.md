# Angular assessment interface

Angular standalone component with local JIT compilation for this reference demo. Start the .NET or NestJS assessment API on port 8000. Run `pnpm install --frozen-lockfile` and `pnpm dev` here, then open the Vite address. Run `pnpm build` for the browser bundle. It reads the real API configuration and provides submission, instructor feedback, versioned publication and audit views. This demonstration does not use a production Angular deployment pipeline.
